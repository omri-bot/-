# מה מותר לסוכן לבצע לבד ומה דורש אדם

## שלב נוכחי: קריאה + טיוטות

`ALLOW_LIVE_WRITES=false`. אין הפעלת קמפיינים חיים ואין שינוי תקציב בפועל.

### מותר בלי אישור (ירוק)
- משיכת נתוני ביצועים מכל הרשתות.
- קריאת מבנה חשבון, קמפיינים, קהלים ונכסים קיימים.
- יצירת קבצים בתוך `clients/` — קופי, בריפים, אסטרטגיה, דוחות, יומנים.
- יצירת ויזואלים ל-`creatives/`.
- כתיבת payload ל-`campaigns/<x>/drafts/` — אחרי מעבר `compliance`.

### דורש אישור אדם (אדום)
- כל קריאת API שמשנה מצב ברשת: יצירה, עדכון, הפעלה, השהיה, מחיקה.
- העלאת קמפיין, גם כ-`PAUSED`.
- כל שינוי תקציב או הצעת מחיר.
- העלאת קהל מותאם.
- קמפיין בקטגוריה מוגבלת (`compliance.md`).
- שינוי בקבצי `policies/` או ב-`client.yaml`.

## איך אישור עובד

1. הסוכן כותב את הפעולה כ-payload ל-`campaigns/<x>/drafts/<timestamp>-<action>.json`,
   כולל שדה `rationale` — למה זה מוצע.
2. `compliance.py` מטביע בקובץ את תוצאת הבדיקה. נכשל → הקובץ לא נכתב.
3. אדם קורא, ומאשר במפורש.
4. רק אז מותר לבצע. `audit.py` מתעד את הקריאה ב-`data/runs/`, והמזהים שחזרו
   נכתבים ל-`campaigns/<x>/state.yaml`.

## כללי ברזל

- אין עקיפה של `approvals.py` בקריאה ישירה ל-API של רשת.
- "האדם אישר קודם משהו דומה" אינו אישור. אישור תקף לפעולה אחת.
- בספק — טיוטה, לא ביצוע.
